Eddy currents — time-harmonic Maxwell

Stage 48 added a time-harmonic eddy-current solver on top of the H(curl) Nedelec basis from magnetostatics. It lives in crates/molla-fem/src/eddy_current.rs (~1450 lines, including the AMS preconditioner) and solves the complex curl–curl–mass system that arises from the Fourier transform of Maxwell’s equations.

Problem statement

Solve the time-harmonic vector-potential equation

\[ \nabla \times (\nu , \nabla \times \mathbf{A}) + i \omega \sigma \mathbf{A} - \omega^2 \varepsilon \mathbf{A} = \mathbf{J} \quad \text{in } \Omega \]

with \( \mathbf{n} \times \mathbf{A} = 0 \) on \( \partial \Omega \), where:

  • \( \mathbf{A} = \mathbf{A}{\text{re}} + i \mathbf{A}{\text{im}} \) is the complex magnetic vector potential (one tangential DoF per mesh edge in each of the real and imaginary parts).
  • \( \nu = 1/\mu \) is the magnetic reluctivity (real, per cell).
  • \( \sigma \) is the electric conductivity (real, per cell — only the conductor cells have non-zero values).
  • \( \omega = 2\pi f \) is the angular frequency (a single global scalar).
  • \( \mathbf{J} = \mathbf{J}{\text{re}} + i \mathbf{J}{\text{im}} \) is the source current density (one complex Vec3 per cell).
  • \( \varepsilon \) is electric permittivity (typically negligible at the frequencies of interest; included for completeness).

The off-diagonal \( i \omega \sigma \mathbf{A} \) term couples real and imaginary parts — this is the skin-effect mechanism that causes high-frequency fields to decay exponentially into a conductor.

Block-real reformulation

The complex unknown is split into \( (\mathbf{a}{\text{re}}, \mathbf{a}{\text{im}}) \in \mathbb{R}^{2N} \) (where \( N \) is the number of edges). Writing the curl–curl block as \( K_{\text{curl}} \) and the Nedelec mass scaled by conductivity as \( M_\sigma \), the discrete weak form becomes

\[ \begin{cases} K_{\text{curl}} \mathbf{a}{\text{re}} - \omega M\sigma \mathbf{a}{\text{im}} = \mathbf{f}{\text{re}} \ \omega M_\sigma \mathbf{a}{\text{re}} + K{\text{curl}} \mathbf{a}{\text{im}} = \mathbf{f}{\text{im}} \end{cases} \]

i.e. in block form:

\[ \begin{pmatrix} K_{\text{main}} & K_{\text{off}} \ -K_{\text{off}} & K_{\text{main}} \end{pmatrix} \begin{pmatrix} \mathbf{a}{\text{re}} \ \mathbf{a}{\text{im}} \end{pmatrix} = \begin{pmatrix} \mathbf{f}{\text{re}} \ \mathbf{f}{\text{im}} \end{pmatrix} \]

with \( K_{\text{main}} = K_{\text{curl}} + \varepsilon M_N \) (tiny mass regularisation for the gradient gauge — same trick as magnetostatics) and \( K_{\text{off}} = -\omega M_\sigma \).

The full \( 2N \times 2N \) system is non-symmetric when \( M_\sigma \ne 0 \), so we use restartable GMRES instead of CG.

Solvers — three paths

solve_eddy_current_steady (v1) — Jacobi-preconditioned GMRES

The simplest path: build the block-real 2N × 2N system, extract its diagonal as the Jacobi preconditioner, and run restartable GMRES. This works on any system and is the right starting point for correctness validation. For the v1 skin-depth contract test, it converges in ~50 GMRES iterations.

solve_eddy_current_steady_ams (v2) — Auxiliary-Maxwell Solver

For larger systems the Jacobi preconditioner stalls because the curl-null space (gradients of P1 scalars) is left unaddressed. The Auxiliary Maxwell Solver (Hiptmair–Xu 2007) decomposes the preconditioning into:

  1. A “scalar auxiliary” Poisson solve in the H¹ space (handled by the multigrid hierarchy) — corrects the gradient component.
  2. A “vector auxiliary” Poisson solve in the P1 vector space — corrects the divergence-free component.
  3. A Jacobi smoother on the edge DoFs themselves.

The combination is provably mesh-independent under the discrete Helmholtz decomposition — iteration count stays bounded as h → 0.

build_discrete_gradient, build_p1_vector_interpolation, and build_p1_vector_laplacian are the ingredients:

#![allow(unused)]
fn main() {
pub fn build_discrete_gradient(mesh: &FemMesh) -> Result<BsrMatrix>;
pub fn build_p1_vector_interpolation(mesh: &FemMesh) -> Result<BsrMatrix>;
pub fn build_p1_vector_laplacian(mesh: &FemMesh, dim: usize) -> Result<BsrMatrix>;
}

The first returns the discrete gradient \( G : \mathbb{R}^{n_{\text{verts}}} \to \mathbb{R}^{n_{\text{edges}}} \) that maps a nodal scalar to its tangential edge-integral (entries \( \pm 1 \) only — orientation-dependent). The second returns the Π interpolation \( \Pi : (P1)^3 \to \text{Nedelec} \) whose edge row integrates the average endpoint vector field along the canonical edge: \( (\Pi u)_e = \frac{1}{2}(u_a + u_b) \cdot (x_b - x_a) \). The third assembles the \( \mu \int \nabla u : \nabla v \) Laplacian on P1 vector space.

Stage 48 v5 enables the Π branch in AmsPreconditioner::apply by default. The preconditioner now combines edge Jacobi smoothing, the scalar gradient branch, and the vector-nodal Π branch. The latter uses a fixed-iteration CG solve on the pinned vector-P1 Laplacian so the overall preconditioner remains linear for GMRES. For compatibility experiments, AmsPreconditioner::with_pi_projection(false) restores the old gradient-only action.

solve_eddy_current_steady_ams_mg (v3) — AMS + Multigrid V-cycle

The v3 path replaces the auxiliary-block scalar solver with a geometric multigrid V-cycle on a uniformly refined mesh hierarchy. See multigrid for the V-cycle structure. Empirically this cuts the iteration count on the larger eddy fixtures (32³ tets) by 4–5× over the v2 fixed-iter CG.

solve_eddy_current_steady_ams_block (v6) — block-coupled AMS

The v6 path targets high ωσ, where the off-diagonal ±ω M_σ block dominates and a purely block-diagonal preconditioner stalls. It keeps the AMS action as the approximate inverse for K_main, but applies a fixed number of stationary refinement sweeps against the full block-real operator:

z0    = D^-1 r
z{i+1}= z{i} + D^-1 (r - A z{i})

where D^-1 means “apply AMS independently to the real and imaginary halves”. Because EddyCurrentConfig::block_precond_sweeps is fixed for the whole solve, this is still a linear preconditioner and remains safe inside GMRES. block_precond_sweeps = 1 recovers the old decoupled action; the default is 2.

Frequency sweeps and Coulomb-gauge projection

solve_eddy_current_frequency_sweep runs the same problem over a list of angular frequencies, using one of:

#![allow(unused)]
fn main() {
pub enum EddyCurrentSolveMode {
    Jacobi,
    Ams,
    AmsBlock,
}
}

Each returned EddyFrequencySweepSample records the sampled omega, the EddyCurrentResult, and the remaining discrete gauge residual. When gauge enforcement is requested, both real and imaginary edge potentials are projected by solving

(G^T G) φ = G^T a
a_gauge = a - Gφ

where G is the discrete P1-to-Nedelec gradient. Pinned edge values are restored after projection, so boundary Dirichlet conditions are preserved. This removes the report-facing gradient ambiguity without changing the curl field used by the physical validation tests.

AmsPreconditioner

#![allow(unused)]
fn main() {
pub struct AmsPreconditioner {
    g: BsrMatrix,                 // discrete gradient
    k_aux_scalar: BsrMatrix,      // H¹ Laplacian
    pi: BsrMatrix,                // vector-P1 -> Nedelec interpolation
    k_aux_vector: BsrMatrix,      // P1 vector Laplacian
    diag_smoother: Vec<Real>,     // Jacobi smoother diagonal
    aux_solver: AuxSolver,        // CG or V-cycle
    mg_hierarchy: Option<MeshHierarchy>,

}

impl AmsPreconditioner {
    pub fn build(mesh, map, k_main, n_aux_iters, ...) -> Result<Self>;
    pub fn apply(&self, r: &[Real]) -> Vec<Real>;
}
}

apply(r) computes \( M^{-1} r \) where \( M^{-1} \) is the AMS preconditioner action — three sub-steps fused into one call. The mg_hierarchy slot is None for the v2 path and Some(...) for v3.

EddyBlockOp — block-real GMRES operator

#![allow(unused)]
fn main() {
pub struct EddyBlockOp<'a> {
    k_main: &'a BsrMatrix,
    k_off: &'a BsrMatrix,
    n: usize,
}
}

implements the LinearOperator trait expected by gmres — exposes mv(x, y) over the block layout x = [a_re ; a_im], y = [...]. This is the way to avoid actually assembling the full \( 2N \times 2N \) matrix (which would double the memory cost) — instead we just dispatch two scalar matvecs per block-matvec.

Skin-depth contract test

The Stage 48 test eddy_current_skin_depth_decay solves the eddy-current problem in a conducting half-space with a tangential boundary current at the free surface. The analytic solution decays exponentially with depth at the skin depth

\[ \delta = \sqrt{\frac{2}{\omega \mu \sigma}}. \]

At the test frequency (\( f = 60 \) Hz, copper-like \( \sigma = 5.96 \times 10^7 \) S/m, \( \mu = \mu_0 \)), \( \delta \approx 8.5 \) mm. The solver matches the analytic decay profile to ~3 % at 16³ tet resolution and within a few percent of the phase shift between real and imaginary parts.
