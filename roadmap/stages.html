Reading the table

Each row is a single brick on the wall. The total count is 597 commits on main at the time of this snapshot, spanning Stage 0 through Stage 51. 132 viewer scenes (numbered through #124, plus unnumbered extras) correspond to a subset of these stages (some stages don’t add a scene, e.g. infra work).

For the chronological commit log run:

git log --oneline main

For the per-stage long-form rationale, design rationale, deliverable list, and DoD (definition-of-done), open PLAN.md.

See open.md and oos.md for the things that are not on this list.
