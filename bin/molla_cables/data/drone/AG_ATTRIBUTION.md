# Procedural agricultural aircraft

The AG aircraft is original procedural geometry generated by `src/ag_drone.rs`.
No downloaded manufacturer mesh, photograph or texture is included in this model.

Visual references, reviewed 2026-11-19:
- DJI Agriculture, AGRAS T25: https://ag.dji.com/t25
- DJI T25 specifications: https://ag.dji.com/t25/specs
- XAG, P100 Pro: https://www.xa.com/en/p100pro
- XAG P100 Pro specifications: https://www.xa.com/en/p100pro/p100prospecs

References inform industrial construction and silhouette, not exact dimensions
or performance. This compact four-rotor design retains Molla's illustrative
flight dynamics and shared spray/wind model. It is not a manufacturer replica
or an endorsed or calibrated agricultural application tool.

See repository `ACKNOWLEDGEMENT.md` [32]–[41] for flight, airflow and spray sources.
The separately imported Mavic and generic quadcopter assets retain their own
attribution files; neither is used for this procedural AG geometry.
